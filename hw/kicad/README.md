## Schematic capture order

### Frontend

1. power + test points
2. ESP32-P4-Core-DEV-KIT carrier connectors / keepouts
3. 8-DSI-TOUCH-A connector/power interface
4. shared I2C: touch/display + TCA8418 + 2× PCA9956B
5. MCP3208 + 4× dual-track RV112FF
6. 2× PCNT encoder connections
7. button matrix
8. LEDs
9. DIN MIDI in/out
10. USB/MIDI connector strategy
11. backend UART/SPI connector

### Backend carrier

1. VisionSOM SODIMM200 socket and power/control
2. JTAG/recovery/reset
3. microSD/USDHC1
4. USB1 service/MSC
5. frontend UART + reserved LPSPI4
6. SAI1 connector to analog board
7. LPSPI1 + CV/codec control GPIO
8. analog-board connector
9. power distribution/test points

### Analog voice

1. power rails and local regulation
2. AD1938 + references/decoupling/SPI/SAI
3. sampling input pair
4. one complete DAC→SSI2140→SSI2190 prototype lane
5. CV DAC/reference/control conditioning
6. repeat lanes 1–7 only after lane 0 ERC/design review
7. left/right mixer/output stages
8. external audio jacks/protection

## ERC rules

- All connector pins get explicit direction/power intent.
- No-connect pins are explicitly marked; never leave module pins ambiguous.
- Add test points to every supply and first-revision bus.
- Use net names from `../interboard-interface.md` exactly.
- Power flags exist only where the board actually sources a rail.
- Do not suppress ERC warnings globally; document each intentional exception.

## PCB rules

Board stack-ups and impedance values are fabrication-dependent and must be entered only after a fabricator is chosen.

General minimums:

- frontend: 4 layers,
- backend carrier: 4 layers minimum; 6 preferred if routing density warrants,
- analog voice: 4 layers minimum; 6 preferred.

High-speed rules:

- MIPI DSI stays within the Waveshare-supported carrier/cable path for Rev A; a future direct-FPC carrier requires a controlled-impedance DSI rule set.
- SAI MCLK/BCLK/FSYNC require uninterrupted ground return and optional source termination footprints.
- USDHC and USB must follow NXP/vendor routing guidance.
- Keep SPI/SAI clocks away from codec references, CV references, SSI2140 controls and high-impedance analog nodes.

## Library policy

- Prefer manufacturer-provided symbols/footprints/3D models where available.
- Import SomLabs' published VisionSOM SODIMM library and verify it manually against the datasheet pin table before use.
- Custom footprints require dimension-source links in their description.
- Do not assume a DigiKey/Mouser autogenerated footprint is correct without package-drawing comparison.

## Release gate

No Gerber release until every `fabrication blocker` in the corresponding electrical spec is closed or deliberately waived in a hardware review commit.
